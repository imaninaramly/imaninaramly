Learning Laravel routes

16 May 2026 · Imanina Ramly

When I first started learning Laravel, I didn’t understand anything about the routes/web.php file.

I remember seeing something like this for the first time:

Route::get('/', function () {
    return view('welcome');
});

And I thought: “Okay… but how does this actually work?”

At the time the whole thing felt a bit unreal. I typed a URL into the address bar, and Laravel showed me the right page automatically.

Then I decided to try it myself and create my first route, /about.

It worked, and I realised that every URL on my site corresponds to something inside web.php.

The other thing I discovered was controllers. They let me organise my code better instead of putting everything in web.php.

Today, when I look at routes/web.php, I see a map of my application — very simple, but extremely powerful.

Such a small part of a framework can turn out to be very important.
